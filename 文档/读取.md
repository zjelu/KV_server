## char[] 和 std::string 的区别

这两个都能保存字符字节，但管理方式不同。
- C 风格数组
char buffer[4096];

它表示：

栈上预留了 4096 字节空间。

可以交给 read()：ssize_t n = read(fd, buffer, sizeof(buffer));

- C++ 字符串
std::string contents;

它会自动管理内存，可以动态增长。

例如：contents.append(buffer, n);

表示：把 buffer 前 n 个字节加入字符串。

所以常见模式是：
char buffer[4096];
std::string contents;

ssize_t n = read(fd, buffer, sizeof(buffer));
if (n > 0) {
    contents.append(buffer, static_cast<std::size_t>(n));
}

## 4. 系统调用是什么
系统调用是：

用户程序向操作系统内核请求服务的接口。
read()
write()
open()
close()
lseek()
socket()
accept()

使用裸指针；
使用整数 fd；
使用返回值表示成功或失败；
使用 errno 表示错误原因；
不自动管理资源；
不知道 std::string、类、异常这些 C++ 概念。

## 7. 为什么之前的代码会混乱

你之前写了：
std::ifstream file;
read(fd_, file.data(), file.size());

而 std::ifstream 是：一个负责读取文件的高级对象。
它不是字节容器，也没有：data(). size()

路线 A：纯 POSIX
char buffer[4096];
read(fd_, buffer, sizeof(buffer));

路线 B：纯 C++ 文件流
std::ifstream file(path);
std::getline(file, line);
